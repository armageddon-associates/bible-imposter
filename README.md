# Bible Imposter

A Bible-themed pass-and-play party game for church youth groups, Bible studies, and friends. Gather 3–20 players around one device, give clues, and vote to find the hidden Imposter.

## Play

Start at `index.html` using a local web server. Add 3–20 unique player names and start; Imposters, the Bible word or pair, and the game mode are selected automatically. The default role policy is 1 Imposter for 3–6 players, 2 for 7–12, and 3 for 13–20. Category preferences, timers, and the final guess are optional settings. Each game randomly chooses one of two modes:

- **Different Word:** Civilians share a Bible-related word; Imposters receive a related word.
- **Hidden Bible Word:** Civilians share a word; Imposters receive no word and infer it from clues.

Players privately reveal roles, give one clue each, then move directly to private voting. The host can start voting early, and the clue timer also starts voting automatically when it expires. Votes are concealed until closed. Ties lead to a revote among tied players; a second tie eliminates nobody. Civilians win when no Imposters remain. Imposters win when they equal or outnumber the Civilians. If enabled, the last eliminated Imposter gets one final guess.

Choose **Elimination Every Round** (the default) or **Fixed Number of Rounds** (1–20, default 5). Fixed mode counts a full voting cycle, including a tie that ends with no elimination. Eliminated players stay out. Standard victory conditions still end the game immediately; otherwise, the team with more surviving players wins after the final round, and equal counts are a draw. The fixed-round ending shows remaining roles and the original word assignment.

The optional **Give Imposter a Clue** setting adds a private, curated topic hint to Imposter role cards in both modes. Civilian words show a Malayalam equivalent when a reviewed word-bank translation is available. Unknown translations are left blank rather than generated by transliteration.

## Run locally

Requires Node.js 18+ for the local server and included test runner. The site has no third-party runtime dependencies, so there is nothing to install with `npm install`.

```sh
npm run start
```

Then open `http://127.0.0.1:4173`. The server can also use a different port by setting `PORT` (for example, `PORT=8080 npm run start`).

Alternatively, if Python is installed:

```sh
python -m http.server 8000
```

Open `http://localhost:8000`. Serve the project root so JavaScript ES modules load from an HTTP origin. `file://` is not supported.

## Word bank

Edit [`js/words.js`](js/words.js). The bundled local bank contains curated Bible-related pairs across characters, places, events, objects, books, teachings, concepts, parables, and miracles. `individualWords` is derived from those pairs for Hidden Bible Word mode. An empty or stale category selection automatically uses the full bank. No external request or user-entered word is required, so gameplay works offline. Related pairs are checked for blank, overlong, and duplicate entries before use.

The game uses biblical vocabulary and original instructions, not copied NIV passages or a proprietary NIV word list. It does not provide Bible quotations or unverified verse citations.

## Tests

Run the pure game-engine tests with Node's built-in runner:

```sh
node --test tests/game-engine.test.js
```

## Deploy

### GitHub Pages

Commit the project to a repository. In **Settings → Pages**, choose **Deploy from a branch**, select the deployment branch and root (`/`), and save. The app uses relative CSS, script, and icon paths and works from a repository subpath.

### Netlify

Create a new site from the repository and set the publish directory to the project root. No build command is needed. For a manual deploy, upload the project directory contents.

## Preferences and privacy

Sound, reduced motion, timer defaults, and category preferences are stored in `localStorage`; player names, roles, words, and votes are not. Active game data remains in browser memory. Secret role content is inserted only after the player taps to reveal. Reveals and votes use handover screens, and the interface clears the private card when continuing. The app uses the Web Crypto API with rejection sampling and Fisher–Yates shuffling.

Pass-and-play privacy is for casual play. Anyone with developer-tools access can inspect client memory, and players can see a private screen if they look. Do not treat this as tamper-proof secrecy.

## Troubleshooting

- If modules fail to load, serve the folder through HTTP/HTTPS instead of opening the HTML file directly.
- If a selected category has no usable word pair or word, the start screen shows an explanatory validation error. Select more categories or add custom words.
- If a preference is stuck or malformed, use **Settings → Clear saved preferences**.
- The clue timer can be disabled in setup. A host can advance clues or start voting early.
- No account, backend, analytics, tracking, external font, image API, or paid API is required.
